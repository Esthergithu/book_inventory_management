# Book Inventory Management System

A beginner-friendly Python project demonstrating Object-Oriented Programming (OOP) through a simple book inventory management system.

## Project Overview

This project allows a bookstore to manage book information, monitor stock levels, calculate inventory value, and estimate potential profit.

## Features

- Create book records with title, author, cost price, selling price and quantity.
- Validate prices and quantities to prevent negative values.
- Calculate total inventory value.
- Update stock when books are added or sold.
- Prevent stock quantities from falling below zero.
- Calculate potential profit.
- Display book details and inventory summaries.

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
